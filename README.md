# 骨牌造境 · Chainline

机关连线不再只是图上的虚线：选中任意一条拉线，它会变成桌面上的实体拉线——两个锚定在元件上的端点、可拖动的折点，以及一段可编辑的松弛余量。

## 拉线规则

- **绕障布线**：固定路径与静止松弛环都会检查是否穿过站立的骨牌、触发器、分岔主体以及坡道本体和**坡道卡扣**；冲突段会标红。
- **端点移动复检**：拖动金色端点（等于拖动所锚定的元件）松手后，整条路径重新检查。若只能穿过障碍才接得上，端点弹回原位、原连接保留，并标出全部冲突点；不会删除或改写任何相邻连线 / 触点。方向键微调元件后同样复检。
- **可编辑折点**：拖方形折点塑形，拖线段中点的 `+` 添加折点，双击折点删除。
- **松弛余量**：拖菱形手柄或面板滑杆调整。模拟时松弛段先像鞭梢一样扫过扇形区域，扫倒路径上的边缘骨牌；余量被取尽、线拉紧后，拉力脉冲才会沿余段把机关事件送到终点（`到达时刻 = 源时刻 + 扫掠时长 + delay`）。
- **模拟 / 回放一致**：每次模拟把每条线的节点、松弛参数和扫击命中快照进 `run.wireEffects`；画布按回放时钟纯函数式呈现 蓄力 → 扫掠 → 拉紧传力 → 到达闪光，拖动回放进度条可逐帧复查。

自带示例「逆风转角 · 拉线」中，`13 → 侧绕铃` 这条长线从分岔下臂末端出发，下潜、绕过分岔两臂的右侧端点并从上方折回；竖直段的松弛环会在模拟中扫倒桌沿的「边缘牌」，随后拉紧并敲响「侧绕铃」。

左侧机关面板还提供：

- **自动绕障**：网格 A* + 视线抽稀生成无冲突折点；端点被障碍埋住时明确报失败并保留原线。
- **端点移动自检**：不改文档的一键验证，演示非法端点移动会被拦截、弹回且相邻 `c1/c2` 触点原样保留。

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本地地址。

## 校验

```sh
npm run typecheck
npm run build
npm run verify:wires   # 绕臂路径 / 边缘牌扫倒 / 端点移动复检 的确定性断言
```

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8032>。端口可通过 `DOMINO_LAB_PORT` 修改。
